# NHWAVE_AMP


NHWAVE_amp is a series of pre-processing and post-processing scripts for the NHWAVE hydrodynamic model compiled in a Python module. This module follows the lead of the FUNWAVE_amp module developed for FUNWAVE-TVD. The core goals are to:

- Create a consistent way to generate input files for large suites of NHWAVE simulations.
- Create memory-efficient structures to store the outputs of simulations in these suites.
- Automate common post-processing functions.
